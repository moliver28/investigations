## How to Get This Data (Manual)

`https://atip.piercecountywa.gov/app/v2/parcelSearch/search`

Search by owner name for each member. Parcel data includes:
- Assessed value and tax history
- Ownership history
- Building characteristics (sqft, bedrooms, year built)
- Sales history
